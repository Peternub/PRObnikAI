# AI-Пробник ОГЭ

Веб-приложение для прохождения пробных экзаменов и разбора ошибок. Node.js 22.17+, PostgreSQL, ЮKassa и LLM API. Интерфейс и документация на русском языке.

## Локальный запуск

```powershell
npm install
Copy-Item .env.example .env
npm start
```

Откройте http://localhost:3000. По умолчанию включён локальный деморежим: данные сохраняются в `.data`, код входа показывается на экране. В рабочем режиме коды отправляются по SMTP, данные хранятся в PostgreSQL. Секреты из `.env` не попадают в Git.

Подготовка рабочего окружения и известные ограничения: [инструкция запуска](docs/DEPLOY.md). Коммерческий запуск требует утверждённых банков, полноценных экзаменационных форматов и проверки интеграций. Текущая версия — работающий учебный прототип.

## Проверка

```powershell
npm run check
npm test
```

## Предметы и учебные варианты

В каталоге 14 направлений: математика, русский язык, физика, химия, биология, география, история, обществознание, информатика, литература, английский, немецкий, французский и испанский языки. Математика содержит 25 авторских заданий (31 балл, 235 минут). Остальные направления содержат сокращённые учебные варианты на 25 минут. Аудирование, изложение, устная часть и лабораторные работы в учебные варианты не включены. Все варианты явно отмечены как учебные.

Задания и критерии находятся в `server/bank.js`. Перед продажей нужно заменить учебный банк полноценными вариантами, утвердить предметные критерии, шкалы и установить `demo: false` у утверждённых вариантов и `BANK_APPROVED=true`. Одного флага окружения недостаточно для продажи текущих учебных вариантов. Для математики используется рекомендованная шкала 2026 года с минимумом 2 балла за геометрию; для сокращённых вариантов — явно обозначенная тренировочная шкала.

Сверять спецификации и шкалы для выбранного года нужно по [материалам ФИПИ](https://fipi.ru/oge/demoversii-specifikacii-kodifikatory), [шкале 2026 года](https://doc.fipi.ru/oge/normativno-pravovye-dokumenty/02-20_25.02.2026.pdf) и [длительности 2026 года](https://doc.fipi.ru/oge/normativno-pravovye-dokumenty/oge2026.pdf).

## Платежи и проверка

ЮKassa использует перенаправление и серверную проверку статуса: возврат пользователя со страницы оплаты сам по себе не выдаёт доступ. Проверяются сумма, валюта, статус `succeeded`, признак `paid` и идентификатор заказа. Повторные запросы используют один ключ идемпотентности. Повтор того же варианта после получения результата стоит 224,25 ₽ вместо 299 ₽. Новый вариант должен иметь новую `version` и продаётся за полную цену.

Заполните `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` и налоговую настройку `RECEIPT_VAT_CODE` для своего магазина. Настройте фискализацию в кабинете провайдера. Документация: [процесс оплаты](https://yookassa.ru/developers/payment-acceptance/getting-started/payment-process).

Развёрнутые ответы проверяются через [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat) с изображениями и JSON Schema. Настройки: `OPENAI_API_KEY` и `OPENAI_MODEL`. В деморежиме внешний ИИ не вызывается: приложенное решение отправляется на перепроверку. При ошибке API, низкой уверенности или неоднозначном ответе баллы за задание не включаются в подтверждённую сумму; результат помечается предварительным. Автоматической «экспертной» оценки без модели нет. Панель ручного эксперта в текущую версию не входит.

Таймер считается на сервере. По истечении времени работа автоматически завершается, даже если вкладка закрыта. Фоновая очередь проверок восстанавливается из базы после перезапуска сервера. Одновременно обрабатывается одна работа.
