# AI-Пробник ОГЭ

Веб-приложение для прохождения пробных экзаменов и разбора ошибок. Node.js 22.17+, PostgreSQL, ЮKassa и LLM API. Интерфейс и документация на русском языке.

## Локальный запуск

```powershell
npm install
Copy-Item .env.example .env
npm start
```

Откройте http://localhost:3000. По умолчанию включён локальный деморежим: данные сохраняются в `.data`, код входа показывается на экране. В рабочем режиме коды отправляются по SMTP, данные хранятся в PostgreSQL. Секреты из `.env` не попадают в Git.

## Проверка

```powershell
npm run check
npm test
```
