# Шрифты проекта

`GrowlingSHA.otf` предоставлен пользователем для этого проекта. Подключён локально, без запросов к внешним шрифтовым сервисам. Перед публичным коммерческим размещением владелец проекта должен иметь право на веб-использование шрифта. Текущий файл — Growling SHA; отдельное начертание Bold Italic пользователем не предоставлено.

Growling SHA используется в основных заголовках, крупных акцентах и логотипе. Основной текст, навигация, кнопки, подписи и поля ввода используют семейство `00361 V3` из предоставленного пользователем архива `00361.zip`. Файлы `Text-*.ttf` содержат обычное, курсивное, среднее, полужирное, жирное и сверхжирное начертания. Все шрифты загружаются с самого сайта.
