# Шрифт проекта

`GrowlingSHA.otf` предоставлен пользователем для этого проекта. Подключён локально, без запросов к внешним шрифтовым сервисам. Перед публичным коммерческим размещением владелец проекта должен иметь право на веб-использование шрифта. Текущий файл — Growling SHA; отдельное начертание Bold Italic пользователем не предоставлено.
